# CampusConnect Development Rules

## File naming

Use camelCase for JavaScript files:

- healthController.js
- healthRoutes.js
- errorHandler.js

Use PascalCase for classes and Mongoose models:

- User.js
- Department.js
- ApiError.js
- ApiResponse.js
